# Система ежедневного резервного копирования на основе rsync

## Обзор

Эта система предназначена для создания автоматических ежедневных инкрементальных резервных копий критически важных данных и конфигураций системы на отдельный носитель. Она также включает скрипт для быстрого восстановления системы из бэкапа.

## Компоненты

1.  `daily_backup.sh`: Основной скрипт, выполняющий резервное копирование.
    - Копирует `/home/<user>`, `/etc`.
    - Сохраняет список установленных пакетов.
    - Сохраняет `crontab` пользователя `root`.
    - Исключает кэш и директории `snap`.
    - Ведет лог в `/var/log/daily_backup.log`.
2.  `recovery.sh`: Скрипт для автоматического восстановления на новой системе.

---

## Инструкция по развертыванию

### Шаг 1: Подготовка системы и диска

1.  **Подключите диск для бэкапов.** Убедитесь, что система его видит (например, с помощью `lsblk`). В данном руководстве мы предполагаем, что диск — это `/dev/sdf1`.

2.  **Создайте точку монтирования:**
    ```bash
    sudo mkdir -p /mnt/ufiles
    ```

3.  **Настройте автоматическое монтирование:**
    - Узнайте UUID вашего диска: `sudo blkid -s UUID -o value /dev/sdf1`
    - Откройте `/etc/fstab` для редактирования: `sudo nano /etc/fstab`
    - Добавьте строку, заменив `YOUR_UUID` на UUID вашего диска:
      ```
      UUID=YOUR_UUID /mnt/ufiles ext4 defaults 0 2
      ```
    - Смонтируйте все диски: `sudo mount -a` и проверьте `df -h`.

4.  **Создайте структуру директорий на диске для бэкапов:**
    ```bash
    sudo mkdir -p /mnt/ufiles/daily_backups/home
    sudo mkdir -p /mnt/ufiles/daily_backups/etc
    ```

### Шаг 2: Установка и настройка скрипта

1.  **Скопируйте скрипт `daily_backup.sh`** из этой директории в `/usr/local/bin`:
    ```bash
    sudo cp daily_backup.sh /usr/local/bin/daily_backup.sh
    ```

2.  **Сделайте его исполняемым:**
    ```bash
    sudo chmod +x /usr/local/bin/daily_backup.sh
    ```
    *Примечание: Перед использованием убедитесь, что переменные `SOURCE_HOME` и пути к бэкапам внутри скрипта соответствуют вашей системе.*

### Шаг 3: Настройка автоматизации

1.  **Откройте `crontab` для `root`:**
    ```bash
    sudo crontab -e
    ```

2.  **Добавьте задание** для ежедневного запуска в 2:30 ночи:
    ```
    30 2 * * * /usr/local/bin/daily_backup.sh
    ```

### Шаг 4: Первый запуск и проверка

1.  **Запустите скрипт вручную,** чтобы убедиться, что все работает:
    ```bash
    sudo /usr/local/bin/daily_backup.sh
    ```

2.  **Проверьте лог** на наличие ошибок:
    ```bash
    cat /var/log/daily_backup.log
    ```

3.  **Убедитесь, что файлы бэкапа созданы:**
    ```bash
    ls -l /mnt/ufiles/daily_backups/
    ```

## Инструкция по восстановлению

**Внимание:** Этот процесс предназначен для выполнения на **новой, чистой установке Ubuntu**.

1.  **Подключите диск с бэкапами** к новой системе.
2.  **Скопируйте скрипт `recovery.sh`** на домашнюю директорию.
3.  **Сделайте его исполняемым:**
    ```bash
    chmod +x recovery.sh
    ```
4.  **Запустите скрипт с правами `sudo`:**
    ```bash
    sudo ./recovery.sh
    ```
5.  Скрипт автоматически смонтирует диск, установит все ранее установленные программы, восстановит системные настройки, домашнюю директорию и задания `cron`.
6.  После завершения работы скрипта рекомендуется перезагрузить компьютер.
